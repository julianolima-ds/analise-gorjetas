# Análise Exploratória de Dados - Dataset Tips

Este projeto tem como objetivo analisar o comportamento das gorjetas em um restaurante utilizando o dataset "Tips" do Seaborn.

## Objetivos

- Analisar o valor médio das gorjetas.
- Verificar a relação entre o valor da conta e a gorjeta.
- Comparar os dados entre os turnos (Almoço e Jantar).
- Identificar quais dias da semana geram maior retorno em gorjetas.

## Tecnologias Utilizadas

- Python
- Pandas
- Seaborn
- Matplotlib
